# Bandmates

Discover bands, browse musician profiles, and find people to play with in your area.

**Category:** Social  
**Live:** [bandmates.freeappstore.online](https://bandmates.freeappstore.online)

## Development

```bash
pnpm install
pnpm dev
```

## Deploy

Push to main — auto-deploys to R2 via GitHub Actions.
